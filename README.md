## ⚡ Features & Highlights

- **Artisan CLI Terminal Emulator**: Live interactive Artisan prompt supporting `php artisan list`, `php artisan pooja:bio`, `php artisan pooja:skills`, `php artisan test`, `php artisan route:list`, `composer show`.
- **Interactive API Debugger & Code Studio**: Execute simulated REST API calls, inspect response status headers, memory usage, latency stats (<15ms), Laravel Telescope SQL traces, and PSR-12 `Controller.php` code tabs.
- **Octane Enterprise Pipeline Diagram**: Visual breakdown of *Cloudflare CDN → Nginx → Laravel Octane Swoole → Redis Horizon → MySQL Primary/Replica*.
- **Categorized Skills Matrix**: Visual progress meters for PHP 8.3, Laravel 11, Livewire 3, Filament, MySQL, Redis, Docker, React, Inertia.js.
- **Production Project Showcase**: Deep architectural modal popups, code snippets, and live demo links.
- **Dark / Light Theme Toggle**: Signature Laravel Crimson design system with glowing dark default theme.

## 🛠 Local Development

```bash
# Clone the repository
git clone https://github.com/poojadhuri123/poojadhuri123.github.io.git

# Navigate into project folder
cd poojadhuri123.github.io

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
